# Hızlı Oku

Linkten veya yapıştırılan metinden kelime kelime hızlı okuma (RSVP) uygulaması.

- `web/` — uygulamanın kendisi (tek HTML, PWA olarak da çalışır)
- `android/` — web uygulamasını saran Android (WebView) projesi; linkleri telefon doğrudan indirir
- `.github/workflows/apk.yml` — her push'ta APK derler (Actions → son çalışma → Artifacts → HizliOku-apk)
